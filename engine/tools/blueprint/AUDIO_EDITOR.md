# Native audio synthesis editor

Save a named project, open Media/Assets and choose Audio. Select sine, triangle, saw, square or deterministic noise; sample rate; start/end frequency, duration, gain, and an ADSR envelope. Attack, decay and release are fractions of the entire sound. Click parameter bars to edit. Mono is the default; toggle Stereo for two channels. The waveform displays the extrema across both channels. Preview uses the actual Redux audio mixer; Stop ends only that preview. Save WAV asset writes a new, byte-verified `asset:sound/synth-N.wav` and never replaces an existing file. Use Assets::sound and Sound.play Blueprint nodes to play it.

Effects opens the original Redux bus-effect controls: low/high pass, distortion, compressor threshold/ratio, reverb, echo, chorus, flanger and three-band EQ, with their native parameter ranges. Adjust the optional tail up to two seconds. Studio runs the original BusEffects DSP on a private 48 kHz stereo buffer, then averages source sample intervals for the chosen rate, fades the last 10 ms and clamps to 16-bit PCM. This bakes effects into preview and export, without modifying the game's live buses. Mono folds the stereo result down; dry stereo duplicates the mono source. Clear effects restores native defaults. A live game's bus settings can additionally affect playback, so baked and live effects should not unintentionally be doubled. The resampler is simple, not studio-grade.

Preset + saves a versioned `sound/synth-N.bptone.json` with all oscillator, envelope, channel and effect settings. Click the preset in Assets to reopen it. It is saved independently of the WAV and neither replaces existing files. Both files travel in the existing portable project ZIP. Invalid preset values or versions are rejected without replacing the active tone.

The source tone is at most four seconds, plus up to two seconds of effect tail. 22.05 kHz mono is the default. Original Xbox has a default 6 MiB sound cache and Redux has 32 mixer voices; the displayed PCM estimate is the generated clip only, not total RAM or actual hardware performance. Use native Cook for ADPCM or Ogg where appropriate. Saw and square are simple oscillators, not band-limited; high notes can alias.

The game needs no editor dependency. Graph-based synthesis and streaming authoring remain separate work. Dual oscillator mode provides separate waveform, pitch sweep, amplitude and ADSR per stereo channel, with shared duration/rate and bus effects. Toggle Editing left/right in Synth. Version 2 presets save both channels; version 1 presets load linked stereo. Runtime Samples, AudioStream, bus effects and playback nodes are available through the existing catalogue.

## Existing audio assets

Click a WAV, Ogg or .adpcm asset in Media to open it in the clip editor. Native loadSound/decodeAll read mono or stereo clips at 8–48 kHz, limited to 8 MiB on disk and 12 seconds of decoded audio. Start/end and fades are fractions of the clip or selected range, respectively. Reverse, normalize, gain, channel conversion, output rate and the Effects tab are non-destructive: Preview and Save WAV asset render a copy, and Save never changes the source. MP3/FLAC must be cooked first. Preset + saves a .bpclip.json referencing the original project asset, with trim, gain, fades, reverse, normalize, output rate/channels and effects. Reopen from Media; the original and preset both travel in the ZIP. A decoded PCM fingerprint detects changed source content; missing or invalid sources are rejected without replacing the active editor. Save WAV asset still exports a new baked sound. The waveform summarizes the rendered output, not the original selection. Long music editing and stream authoring remain separate work.

## Editable runtime graphs

Sample graph and Stream graph save new native .bp.json projects in the save directory. Open from the normal project browser after saving your current project. Sample graph creates native Samples, runs a bounded Repeat over 4096-frame blocks, renders each channel with ADSR/pitch sweep, then plays it. Stream graph creates native AudioStream on enter and retains its handle, scratch array and independent phases; Update fills only available room (max 4096 frames), preserving phase for frames accepted. It uses constant starting pitch and gain, without a finite ADSR or pitch sweep. Both support four oscillator shapes and native editable pins. Noise must be baked as WAV. Effects are not copied from the offline DSP; add native Audio bus nodes explicitly. These are editable normal Blueprint graphs, not a separate modular audio DSP editor. Sample generation happens on enter and may be expensive for long clips on Xbox; prefer baked WAV for predictable loading or use stream blocks for continuous generation.
